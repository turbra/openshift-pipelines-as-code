OpenShift App Template

PaC Event Flow

A lightweight animated view of how a Git push becomes a PipelineRun, an OpenShift binary build, and a deployment rollout in this repository.

GitHub-linked variant of the standalone event-flow reference.
Trigger
1 Git Event

Developer Push

A commit lands on the branch configured in .tekton/pipelinerun.yaml.

Open `.tekton/pipelinerun.yaml`
2 Webhook

Git Provider Notifies PaC

GitLab or GitHub sends the webhook event to the cluster-wide PaC listener.

Open `deployment/pac/02-repository.yaml`
3 Repository CR

Repository Lookup

The PaC controller locates the namespace-scoped Repository object and validates the provider config.

Open `deployment/pac/02-repository.yaml`
4 .tekton

Definition Resolution

PaC fetches the repo content, evaluates CEL filters, and resolves the pipeline and task files from .tekton/.

Open `.tekton/`
Execution
8 Deploy

Apply and Rollout

The deploy task applies manifests from deployment/app, updates the image, and waits for rollout.

Open `.tekton/tasks/openshift-deploy.yaml`
7 Build

OpenShift Binary Build

The build task creates or updates a BuildConfig, starts a binary build, and pushes the image to the configured registry.

Open `.tekton/tasks/openshift-binary-build.yaml`
6 Workspace

Source Workspace

The run uses a PVC-backed workspace so the checked-out source persists across sequential task pods.

Open `.tekton/pipelinerun.yaml`
5 PipelineRun

PipelineRun Created

PaC creates a namespaced PipelineRun and hands execution to Tekton.

Open `.tekton/pipeline.yaml`
Feedback
9 Status

Commit Status Update

PaC reports status back to the Git provider when the configured token has sufficient permission in that environment.

Open `deployment/pac/00-secrets-example.yaml`
Trigger and matching Pipeline execution and deployment Provider feedback loop

This visualization follows the official Pipelines as Code event model, with repo-specific behavior layered on top: repo-local pipeline definitions, OpenShift BuildConfig-based image builds, and a PVC-backed source workspace.
